The Theotokos and Archangels receive the highest display priorities in `data/icons.json`. Images are shown with `object-fit: contain` so icons are not cropped on phones, tablets, laptops, Macs, Windows displays, ultrawide screens, or 4K monitors.

Reuse terms are those stated on each linked Wikimedia Commons file page. Public-domain and CC0 labels are preserved in the app metadata. Review the linked source page before redistributing an image outside this project.
